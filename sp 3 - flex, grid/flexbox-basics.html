Włączenie Flexboxa

  • Elementy potomne układają się w rzędzie/kolumnie
  • Osie: główna (main axis) i poprzeczna (cross axis)

Rozmiar elementów: flex-grow

  • flex-grow określa jak elementy dzielą wolną przestrzeń
  • Wartość 0 oznacza brak rozciągania
  • Im większa wartość, tym większy udział w wolnym miejscu
.item-2 { flex-grow: 1; }
.item-3 { flex-grow: 2; }

Zwężanie elementów: flex-shrink

  • flex-shrink określa jak element kurczy się przy braku miejsca
  • Wartość 0 blokuje zmniejszanie szerokości
  • Większa wartość oznacza szybsze oddawanie miejsca innym elementom
.item-a { flex-shrink: 0; }
.item-c { flex-shrink: 3; }

Początkowy rozmiar: flex-basis

  • flex-basis ustawia bazowy rozmiar elementu na osi głównej
  • Przeglądarka startuje od tej wartości przed przeliczeniem grow i shrink
  • "Zastępuje" width w flexie
.item-a { flex-basis: 120px; }
.item-b { flex-basis: 220px; }

Właściwości pojedynczego elementu

  • order zmienia kolejność wizualną elementów
  • align-self pozwala nadpisać align-items dla jednego elementu
  • Skrót flex łączy grow, shrink i basis
.item-b { order: -1; }
.item-c { align-self: center; flex: 2 1 140px; }
